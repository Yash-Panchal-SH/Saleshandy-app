# Knowledge base

This is a greenfield rebuild — there is no legacy knowledge base to migrate or
de-stale. The old stack (Redux, RTK Query, Formik, TinyMCE, …) is **not** used
here; see [`README.md`](../README.md) for the current stack.

Durable knowledge currently lives in:

- [`rebuild-spec/`](../rebuild-spec/) — the governing specification for the rebuild
- [`docs/adr/`](../docs/adr/) — architecture decision records
- [`docs/runbooks/`](../docs/runbooks/) — operational runbooks

Add longer-form notes and guides here as the project grows.
